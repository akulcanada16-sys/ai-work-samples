RowProof app map

This small guide follows one user action: turning CSV text into an evidence-backed decision.

  1. index.html contains the file picker, text area, key selector, report regions, and download buttons. These are the user-visible places where a CSV enters and a decision leaves.
  2. src/app.js listens for a text/file/sample change, calls the audit, and renders each row-evidenced finding. It also only enables normalized download when the audit says it is safe.
  3. src/csv-core.js parses quoted records and produces the audit. The key reuse practice is: write an edge-case input first, then assert the parser preserves its exact fields before adding a UI feature.

Useful practice for a future project: trace one button or input from its HTML label, through the event listener, to the function that changes the displayed result. This makes it easier to test an agent-built feature deliberately.
