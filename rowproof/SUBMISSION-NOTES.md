# Competition-ready project facts

Use these facts when the entrant writes their own Devpost submission. This file deliberately does not provide submission prose; the Devpost Learn Skill Pack requires the entrant to write that material themselves.

## Facts to communicate

- **Project name:** RowProof
- **Audience:** people who prepare CSV exports for imports, reporting, research, and spreadsheet review.
- **Problem:** CSV defects can remain invisible until a downstream import, analysis, or spreadsheet opening fails or behaves unexpectedly.
- **Working core flow:** paste or choose a CSV → choose an optional key column → read row-level audit evidence → download JSON audit or a safe normalized CSV.
- **Privacy:** fully on-device; no account, API, external service, telemetry, or CSV upload.
- **Novelty:** pairs parser-aware structural evidence with practical spreadsheet-risk checks, and refuses to emit a “clean” export when structure is ambiguous.
- **Built with:** HTML, CSS, and browser JavaScript; no runtime dependencies.
- **AI disclosure:** see the factual disclosure in `README.md`.
